# 🌤️ আবহাওয়া অ্যাপ (Weather App)

একটি সুন্দর এবং মোবাইল-বন্ধুত্বপূর্ণ আবহাওয়া অ্যাপ যা রিয়েল-টাইম আবহাওয়ার তথ্য প্রদান করে।

## 📋 বৈশিষ্ট্য (Features)

✅ **বর্তমান আবহাওয়া** - তাপমাত্রা, বর্ণনা এবং আবহাওয়া আইকন
✅ **বিস্তারিত তথ্য** - আর্দ্রতা, বায়ু চাপ, বাতাসের গতি, দৃশ্যমানতা, UV সূচক
✅ **মোবাইল রেসপন্সিভ** - সব ডিভাইসে নিখুঁত প্রদর্শন
✅ **দ্রুত অনুসন্ধান** - যেকোনো শহর খুঁজুন
✅ **বাংলা সমর্থন** - ইন্টারফেস এবং ডেটা উভয়েই বাংলায়
✅ **সুন্দর UI** - গ্র্যাডিয়েন্ট এবং মসৃণ অ্যানিমেশন

## 🚀 শুরু করার জন্য (Getting Started)

### 1️⃣ API কী সংগ্রহ করুন

1. [OpenWeatherMap](https://openweathermap.org/api) এ যান
2. একটি বিনামূল্যে অ্যাকাউন্ট তৈরি করুন
3. **Current Weather API** সাবস্ক্রাইব করুন (বিনামূল্যে)
4. আপনার API কী কপি করুন

### 2️⃣ API কী যোগ করুন

`script.js` ফাইলটি খুলুন এবং লাইন ২-৩ খুঁজুন:

```javascript
const API_KEY = 'YOUR_API_KEY_HERE';
```

আপনার API কী দিয়ে প্রতিস্থাপন করুন:

```javascript
const API_KEY = 'আপনার_এপিআই_কী_এখানে';
```

### 3️⃣ অ্যাপ খুলুন

`index.html` ফাইলটি আপনার ব্রাউজারে খুলুন বা একটি লোকাল সার্ভার ব্যবহার করুন:

```bash
python -m http.server 8000
# বা
npx http-server
```

তারপর `http://localhost:8000` খুলুন

## 💻 ব্যবহার (Usage)

1. শহরের নাম টাইপ করুন (যেমন: "ঢাকা" বা "Dhaka")
2. **অনুসন্ধান** বোতাম ক্লিক করুন বা Enter চাপুন
3. বর্তমান আবহাওয়ার তথ্য দেখুন
